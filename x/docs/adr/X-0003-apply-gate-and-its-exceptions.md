# a verb that publishes or destroys waits for --apply, with three named exceptions

a verb marked `needsApply` prints its plan and exits 4 with the exact confirm command until `--apply` (a yes/no on a terminal). three families skip the gate on purpose, each because something else already guards it and a second call costs more than it saves:

- `handoff` deletes: the store is disposable by contract ([ADR-0002](../../../docs/adr/0002-handoff-shared-file-store.md)), every removal goes to the macos trash, and the envelope names each file
- `linear` writes (`body --set`, `set`, `link`, `comment`, `update`): the hottest door stays one call; the stale check, the printed actor and linear's own history guard them. `linear archive` keeps the gate ([FRM-344](https://linear.app/x-com/issue/FRM-344), dima 2026-10-07)
- `lane review`: it acts only on a stale verdict under the round cap, its own checks, and a coder's «final» runs it as one call ([FRM-355](https://linear.app/x-com/issue/FRM-355))

a new exception needs the same shape: a guard that already holds, named here.
