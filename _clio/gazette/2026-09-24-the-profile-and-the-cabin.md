## tricks gained
- an orphan branch pushed to a repo with vercel projects is built by every project — the branch must carry each app's `vercel.json` opt-out (6 previews burned, then fixed and proven)
- `gh workflow disable ci.yml` is the «pause CI» while slaying a readme to main; re-enable at the end
- a parallel monitor catches an issue close but is pull-only; nothing notifies until `monitor events` is read
- a `--bg` coder in a shared checkout edits through the shell; `git commit -- <paths>` keeps another session's index out of its commit
- github caches a same-name svg for 5 min; hard reload before judging a redraw
