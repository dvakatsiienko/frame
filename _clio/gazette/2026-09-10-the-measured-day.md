- every cli in a shell loop gets `</dev/null` — the obsidian cli ate the loop's stdin, `ntn api` hangs on an open one
- `ntn api` wants `-X PATCH` and a bare `/v1/…` path; `ntn pages trash` needs `--yes` non-interactively; the obsidian rest api answers 404 to `%2F` and takes a frontmatter patch as `Operation: replace` plus a bare json string

- a ci review run's «success» is not the review — the comments post after; poll them
- `git.deploymentEnabled` cancels rather than skips, and the hobby counter is «created», not «built»
