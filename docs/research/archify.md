# archify: diagrams for our fleet flows, better than Excalidraw?

Checked 2026-11-15, repo HEAD `a7ed6fd6`.

**Verdict: borrow-only. Keep Excalidraw as the blueprint tool.**
- Archify is free (Apache-2.0), very active, and agents generate its diagrams well.
- But it says itself that it is "not a general-purpose WYSIWYG editor". So the "agent draws, dima edits" loop means editing JSON or asking an agent again.
- It has no wireframe type.
- Borrow its typed-IR plus finalize-check pipeline for agent-drawn Excalidraw blueprints. Maybe use it once for a read-only fleet explainer.

## 1. Free, open, alive, how it runs

- **License.** Apache-2.0 (`gh api repos/tt-a1i/archify`, 2026-11-15).
  - Code before commit `25cf3708` stays MIT ([NOTICE](https://github.com/tt-a1i/archify/blob/a7ed6fd6/NOTICE), [LICENSE-MIT](https://github.com/tt-a1i/archify/blob/a7ed6fd6/LICENSE-MIT)).
- **Paid tier.** None. "No hosted plan, account, or paid tier is required" ([llms-full.txt](https://archify.si/llms-full.txt), v3.2.0, fetched 2026-11-15).
  - The README warns that "third-party online services and paid plans" using the name are not Archify ([README_EN](https://github.com/tt-a1i/archify/blob/a7ed6fd6/README_EN.md)).
  - It lists sponsors: Kimi Work, Supercode, OpenLux (same README).
- **Alive.**
  - Created 2026-04-15, last push 2026-11-15. 96,729 stars, 6,616 forks, 360 open issues (`gh api`, 2026-11-15).
  - At least 100 commits since 2026-09-16 (the API page cap), with releases v3.0.1 (09-28), v3.1.0 (10-13) and v3.2.0 (10-19) ([releases](https://github.com/tt-a1i/archify/releases)).
  - Effectively one author: `tt-a1i` has 1,156 commits; the next contributor has 131 (contributors API, 2026-11-15).
  - The star count is unusually high for a 7-month-old repo. Whether it is organic is unverified «?».
- **How it runs.** It is an Agent Skill, not an app.
  - Install: `npx -y skills@latest add https://archify.si --skill archify --agent claude-code --global --copy --yes`, then `node <path>/bin/archify.mjs doctor` ([llms.txt](https://github.com/tt-a1i/archify/blob/a7ed6fd6/llms.txt)).
  - It needs Node for authoring and export. The output is one standalone HTML file "that runs without a build step or network connection" ([llms-full.txt](https://archify.si/llms-full.txt)).
  - The gallery URL from the brief resolves (HTTP 200, `curl -I`, 2026-11-15).

## 2. What it draws, from what input, and whether agents can drive it

- **Ten types:** architecture, workflow, sequence, dataflow, lifecycle, ERD, class, tree, timeline and waterfall. There is also a "one-page explainer" mixing prose, tables, code and diagrams with cited sources ([llms-full.txt](https://archify.si/llms-full.txt) §2).
  - There is no UI wireframe type. Our flows map to workflow, sequence and lifecycle.
- **Input.** "plain language, a plan, existing Mermaid text, or a real Git repository" (same file, §3).
  - It is "not … an automatic diagram extractor for arbitrary repositories" (§5).
- **Agent-generated by design.**
  - The agent writes typed JSON IR. Then `archify finalize` "checks the schema, lays out and routes the geometry, and runs a real-browser inspection before writing the artifact" (§2.1).
  - It works in Claude Code, Codex, Cursor, OpenCode and Copilot (§3).
  - The output supports focus, upstream/downstream reach tracing, path highlighting, themes, and PNG/SVG/WebM export (§2.1).
- **Editing.** It is "not a general-purpose WYSIWYG editor, a hosted collaboration service" (§5). The source you keep is the JSON (§FAQ).

## 3. Head to head with Excalidraw: agent draws, human edits

Context: Excalidraw has been our blueprint tool since 2026-10-30. dima's complaint is that comments are "gated behind a subscription" (`frame/recipes/refresh-blueprint-comms/recipe.md:33,44`).

Archify does better:
- **Layout and routing are computed and browser-checked.** The agent never places coordinates, so lines don't cross or overlap. Raw Excalidraw JSON from an agent needs hand placement.
- **Interactive reading.** Reach tracing ("what does a lane touch downstream?") and path highlighting suit a fleet map that gets read more than it gets drawn.
- **Source-backed explainer panels** with citations, useful for "how a lane works" docs.
- **Fully offline.** No account, a single HTML file you can commit to the repo.

Excalidraw does better:
- **Human editing.** It is a real canvas: drag, restyle, sketch. Archify has none, so every edit goes back through JSON or an agent.
- **Freeform shapes and wireframes.** Excalidraw has a wireframe library; Archify has no wireframe type ([llms-full.txt](https://archify.si/llms-full.txt) §2.1). Archify's own comparison table sends "freehand whiteboarding" to Excalidraw (§4).
- **Agent path exists.** The official [excalidraw/excalidraw-mcp](https://github.com/excalidraw/excalidraw-mcp) (5,679 stars, last push 2026-03-24) streams diagrams with "interactive fullscreen editing" in MCP-App clients. Whether that works inside Claude Code's terminal is unverified «?».
- **Maturity.** [excalidraw/excalidraw](https://github.com/excalidraw/excalidraw) is MIT with 135,730 stars and was pushed today (`gh api`, 2026-11-15). The `.excalidraw` files already have a drift check (`frame/_clio/script/blueprint-drift.ts:32`).
- **Neither** gives free comments. Archify has no comments at all, so it does not fix dima's complaint either.

## 4. Verdict: borrow-only

Archify does not beat Excalidraw for "agent draws, dima edits", because the editing half is missing. Borrow:
1. **Typed IR plus a finalize step.** Have agents write a small typed flow spec (nodes, lanes, edges). A script lays it out into `.excalidraw` JSON and checks for overlaps, instead of agents hand-placing coordinates. Model: `archify finalize` (§2.1).
2. **Optional one-off.** Generate a read-only fleet-map explainer (coordinator, then lanes, then reviewer) with Archify. That would show whether reach tracing is worth having for onboarding docs. Run it in a sandbox; the skill install writes to `~/.claude/skills`.
