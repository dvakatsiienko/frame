# design drift — a small UI ask on a designed app goes to a codie, no designer

dima, 2026-10-11: «let's keep this trial reminding me to run a coder on applicable apps, and change it so it is not only for atelier but for any app that has its design … our design-covered apps are growing; use this trial on any app that is processed via the new design flow (`x:crew-designer`).»

- **the apps it covers**: every app that went through `x:crew-designer` and carries its `DESIGN.md` — atelier today; speak is next, after the memory sweep
- **the policy**: a small UI ask on one of them goes to a coder with the app's `DESIGN.md` and a live screenshot, no designer and no comp (dima, 2026-09-30: «structured layer lives, comps retire»)
- **the measure, per app**: each ask and whether dima rejected the result for a visual reason, one line in the rounds below. over 25 % visual rejections on an app, or a mid-way ask for a comp → the policy is wrong for that app, and a single-take designer pass becomes its default for small asks
- it answers dima's FRM-244 note: «designs are not throwaway. ideally they would be live, and at least ± synced with live app state»
