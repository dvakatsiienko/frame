# readaloud playbook — how to build speak well

the build knowledge for speak: the practices, the bar, the architecture calls and the voice safety rule. `refresh-speak` (`recipes/refresh-speak/`) writes it; a design or build change to speak reads it first.

## the voice safety rule

- before any kokoro engine or model change, the model snapshot and all its voices are backed up; a new version replaces the old one only after dima hears af_heart on it (FRM-669)
