# x-mod-breather

a breathing exercise drawn above the prompt while Claude works, so the wait becomes a breath.

## Language

**Band**:
The row above the prompt the breather draws into while a turn runs; it holds the meter and nothing else.
_Avoid_: bar, strip, panel

**Meter**:
The grid of bars in the band, sline's blocky audio meter: 3 rows of block glyphs on the terminal, 7 rows of squares on the desktop.
_Avoid_: wave, visualizer, equalizer

**Exercise**:
One breathing pattern the meter follows: Coherent Breathing (`hrv`), Physiological Sigh (`sigh`), Box Breathing (`box`), 4-7-8 Breathing (`478`).
_Avoid_: mode, preset, style

**Phase**:
Where the breath is in its cycle: Breathe in, Sip in, Hold, Breathe out, with the seconds left; the spinner reads it.
_Avoid_: step, stage
