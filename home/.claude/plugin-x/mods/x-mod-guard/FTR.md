# x-mod-guard — features

- 🧭 asked, not built yet (a new ask, an experiment) · ⬜ built, not checked yet · 🐞 built, its check fails · ✅ passes in the app's verify recipe · 🔎 dima used it and it holds
- given/when/then lines are sixth sense's exit lines
- makes: lines name what a feature leaves behind — a file, a take, a clipboard item
- decision: lines record a choice and its reason

## every Bash call

- ✅ a floor command is refused with its door
  - given a Bash call runs one of: `rm` or `unlink` (also `xargs rm`, `find -delete`, `find -exec rm`); a kill by pattern (`pkill`, `killall`, a `kill` fed by `pgrep`, `ps`, `grep` or `awk`); `git reset --hard`, `git checkout --`, `.` or `-f`, `git restore` of the worktree, `git clean -f`, `git stash drop|clear`; `git push --force|-f|--force-with-lease|--delete|--mirror` or a `+ref` / `:ref` refspec, `git branch -D` or `-d -f`, `git worktree remove|prune`; `--no-verify` or `--no-gpg-sign` on `git` or `x`, `git commit -n`, `-c commit.gpgsign=false`, `-c user.name|user.email`, `git config user.name|user.email <value>`; a `mv` in the obsidian vault; a `HOME=` or `HOME+=` override (`export`, `declare`, `typeset`, `local`, `readonly` too); `npm -g` or `--location[=]global`; `pip install` (`python -m pip`, `-mpip`)
  - and wherever it sits (one walker, `rules/command.ts`, that every rule reads through, FRM-478): behind `sudo -u <user>`, `env` (its `-S` string run too), `exec`, `script`, `timeout`, `nice`, `xargs`, `caffeinate`, `stdbuf`, `gtimeout`, `flock`, `watch`, `chronic`, `unbuffer`, `pnpm exec|dlx` (past pnpm's own flags: `-C app`, `--filter web`, `-r`, `--dir=x`), `npx`, `bunx`, `pnpx`, `x as <member> --` (its member kept, so `as-dima` reads it), `x gate run --`, a packed flag cluster read as getopt does (`env -vu NAME`); inside `if`, `for`, `while`, `{ … }`, a function body, `coproc`; inside a `$( … )`, a `$(( … ))` or backticks, quoted or not; in a `sh|bash|zsh|dash|ksh -c` script (`-c --`, `-xc` too), a heredoc, `<<<` string (also a `cat <<<` piped in), `echo` (past its `-n`/`-e`) or `printf` (its format filled from its operands) piped into a shell or into `xargs bash -c`, an `ssh` remote command (options and one `--` after the host too) or the heredoc fed to it (also when that command is a shell reading stdin: `ssh box bash -s <<EOF`), a shell or `source`/`.` reading stdin (past `-o <option>`, packed too: `-euo pipefail`; `-s` or `-` with positional args), `su` (its `-c` string, packed `-lc` or `--command=`, or its stdin), `sudo -s` / `-i` with no command (root's shell on stdin), a `$( … )` or backtick in an unquoted heredoc's body (a quoted `<<'EOF'` keeps it text), `/dev/stdin` or a `<( … )`, an `eval`, a `trap` or `alias` string, any git alias (`!` shell text or a plain subcommand, `-c alias.p='push -f'`, the call's own args handed on: `-c alias.p=push p --force`), a `git config [--global] [set] alias.<name> <body>` read as the alias it persists and run for each later git call on the line that names it, its args handed on, a `find -exec` / `fd -x` command; with its name held in a literal variable (`R=rm; $R`, `${R}m`, `${=R}`, `y=$x`, `set -- rm; "$@"`, `$(echo rm)` or `$(echo -n rm)` anywhere, an `eval "$(cat <<EOF …)"`, an unquoted `$(cat <<EOF …)` head split as the shell splits it), every value a variable takes on the line counted (a `for` or `read <<<` value, a conditional rebind, a known value beside one the line cannot read; a prefix `R=x cmd` binds nothing after it), a path held in one (`V="$HOME/…vault"; mv "$V/a.md" …`), a feeder held in one (`P=$(pgrep x); kill $P`), ansi-c quoted (`$'rm'`), split by quotes (`r''m`), by path; git's long flags by any unique prefix (`--har`); every case is a row in `tests/escapes.ts`
  - when x-mod-guard reads it
  - then that one command is refused, and the reason opens with the door: `trash`, `claude stop <id>`, `git stash push -u -- <your paths>`, the `obsidian` cli, `uv pip install`, `brew` / `pnpm add -g`, a run without the flag, `x lane rebase-main` for a force-push (a codie/* branch; any other, «ask clio») — and «ask clio» only for a mirror push (its escape names the remote, `# dima-ok: origin`), a remote branch delete, a local branch delete, `git worktree remove|prune` and a x-mod-stash drop, where no safe door exists
  - proven live 2026-10-05: a headless `claude -p --plugin-dir x-mod-guard` was told to `rm` a scratch file; the call was refused with the trash door, the file stayed, the event landed in x-mod-guard's store
  - decision: a refusal stops one command, never the session — no dialog, so a missed click can never stall codie; codie finds its own way around (dima, FRM-321)
  - decision: quoted text and comments are never read as commands, and a heredoc body only when a shell consumes it — a commit message may name `rm -rf`
  - 📌 not read: a script piped into a shell from a file or the net (`curl … | sh`, `cat x | bash`), a name the shell builds at run time (`$(cmd)`, an unset `$X`), a script language changing its env (`python3 -c 'os.environ…'`); `rmdir`, `truncate`, `git worktree` moves
