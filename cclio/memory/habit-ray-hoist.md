# ray hoist — a repeated ask becomes a raycast candidate, same turn

dima, 2026-09-18: raycast commands in `x-ray` are how his repeatable asks stop costing a session. the
tracker is [FRM-252](https://linear.app/x-com/issue/FRM-252), never a file — a stash only i read is a stash he never culls.

- **the trigger is a repeat**, never a guess: the second time an ask has the same shape (a lookup, a
  paste, a toggle, a list he scrolls), one line lands on FRM-252 in the same turn — `what · the ask it
  replaces · times seen · size`. announce the line in the reply.
- a first-time ask is not a candidate; six guessed candidates were declined in one go.
- cull is his, on his pass; an approved line becomes a coder brief on `main`, the line dies with the commit.
- **the check is mechanical at every «did i just do this before?» moment** — the same shape as the
  skill-list scan; an ask that needs a window or a paste is the tell.
